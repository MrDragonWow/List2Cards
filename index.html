List2Card

Create flashcards from Excel, CSV, or a spreadsheet link.

Manual GPTs ↗

Caution: If browser translation such as Google Translate is on, turn it off before studying. Automatic translation can change the words on your flashcards.

The sheet must be readable as public CSV. First load requires network access.

Caution: Before sharing or loading a Google Sheets CSV link, set the Google Drive sharing permission to Anyone with the link: Viewer.

To understand which lists are being used, this app can record the loaded list link and load time. It does not record names, email addresses, device IDs, or answers.

CSV works offline. Excel requires the import library to be available online.

Local files stay on your device, so shared URL / QR links cannot be created from offline file loads.

Template: Row 1 headers / A:No. / B:Tags / C+:Card fields
